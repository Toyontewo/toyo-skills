# remotion-best-practices

**Source:** https://github.com/remotion-dev/skills

Domain-specific guidance for creating and editing Remotion videos in React.

## Install

```bash
npx skills add remotion-dev/skills
```

Choose the Remotion skills that match your workflow when prompted.

## What it unlocks

- Composition, sequencing, timing, and transition guidance
- Video, audio, captions, fonts, maps, and media workflows
- Studio previews, rendering, upgrades, and Remotion-powered app patterns

The full upstream collection changes alongside Remotion, so it is installed from its source instead of being copied into this repository.
